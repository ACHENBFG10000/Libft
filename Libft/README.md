# Libft

## Description:
**Libft** is a custom C library that re-implements standard C libary funtions(such as 'strlen', 'memcpy', 'atoi'), along with additional utility and linked list (ft_lst) function and all function of this directury star from ```ft_```.

## Instructions:
1. Open your ternimal and navigate to this directory.

2. Write commant
```make``` 
press ENTER key, after you will get "Libft.a" file and the same name of fuction file but end with ".o".

3. You can use ```make clean``` commant to clean that files end with ".o", because after we don't need.

4. To use this library, you need write header ```#include "libft"``` in your C project and when compile your C project must write libft.h back of your C programe.
ex:
```sh
cc -Wall -Wextra - werror project.c libft.a
```
